### Dark theme for Skills Hub

#### Prerequisites
- App is running from this repository, with at least one installed skill.
- Appearance is set to Dark in Settings.

#### Steps
1. Open Skills and inspect the heading, installed skill list and status text.
2. Open a skill detail modal. Inspect its title, close button, README and footer.

#### Expected results
- The skill list, controls and detail modal use dark surfaces with readable
  text and visible interactive states.

#### Cleanup
- Restore the previous appearance preference.
