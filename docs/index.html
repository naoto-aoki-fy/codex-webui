Codex App UI

A browser interface for Codex app-server workflows, with conversations, local files, Skills and MCP servers.

The application runs a Node.js server on Windows or Linux. Desktop and mobile browsers can connect to that host.

Run from source

Use Node.js 22 and the pnpm version pinned in package.json for source development. Install Codex separately and start its app-server on the host that owns the repositories and Codex login (the web backend may connect through an SSH tunnel):

# Separate terminal: codex app-server --listen ws://127.0.0.1:4500
pnpm install --frozen-lockfile
pnpm run build
node dist-cli/index.js --no-open

Open the URL printed by the server and manage Codex authentication in the independently started app-server environment.

The default port is 5900. Use --port to choose another port.
