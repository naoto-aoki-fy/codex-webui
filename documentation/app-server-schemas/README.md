# Protocol snapshot provenance

These are checked-in protocol artifacts, not a list of enabled UI features.
Do not remove schemas for retired UI features: application DTOs still import
TypeScript types through [`src/api/appServerDtos.ts`](../../src/api/appServerDtos.ts).

| Artifact | Verifiable provenance and use |
| --- | --- |
| `typescript/` | Files such as `ClientRequest.ts` identify themselves as generated by upstream `ts-rs`. The exact Codex revision/version and export command are not recorded. |
| `json/` (individual schemas and `codex_app_server_protocol.schemas.json`) | The [protocol reference](../APP_SERVER_DOCUMENTATION.md) records an upstream codegen export including experimental definitions. Exact generator invocation, Codex revision/version, and export environment are unknown. |
| [`src/server/appServerMethods.json`](../../src/server/appServerMethods.json) | Bundled method/notification catalog extracted from the checked-in JSON snapshot, as recorded in the [external-server guide](../../docs/external-app-server.md). The original extraction script/command is not recorded. `MethodCatalog` in the bridge reads this file for metadata endpoints. |

There is no schema regeneration package script or maintained extraction script
in this repository. `pnpm run build` consumes the existing artifacts; it does not
regenerate them. The backend does not invoke Codex schema generation at runtime.
Do not infer a generation command or snapshot version from the installed Codex.

For a future, separately scoped refresh, first establish the upstream version
and supported codegen procedure, record the exact invocation and experimental
flags, then review DTO and catalog compatibility together. Regeneration is outside
this documentation update; all existing schemas and the method catalog are preserved.

The application `ModelListParams` DTO extends the older generated snapshot with
Codex CLI 0.169.0's optional `modelProvider` field. Native discovery passes it on
every provider page, together with `includeHidden: true`. This focused extension
does not claim that the entire snapshot or filesystem generator targets 0.169.0.
